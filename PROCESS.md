## Feedback from a colleague (https://github.com/arkms)

No explanation of how to use the tool was given, and the usage was smooth.

<img width="868" height="197" alt="image" src="https://github.com/user-attachments/assets/e4bfff13-777c-4a10-bf11-498f824a385e" />

Translation: It's cool, simple but enough. But there's small improvements, or feedback. I don't know how complicated it would be, but after sending a message, the message ID field could be updated from the message that has just been sent. Another thing, is that instead of requiring a message ID, that you could also enter the message link, because the message ID is only available on developer mode.

Takeaway: Very useful feedback. It's good to know that there was no friction on the usage, and the feedback was mostly improvements rather than a complaint. I did not realize that the message link already contains the message ID, it just also contains the server and the channel. Using the message link would be far better because that means I can auto select the channel to edit the message from, instead of requiring the user to select the channel + enter the message id.
