## Intended user

Seasoned discord moderators and owners.

The problem: Sometimes you want to send a message on behalf of your company or project. For this, you have a few options:
1. Fire and forget: You just send a message with a discord account that has the name of your company or project. This becomes a headache if there are multiple moderators as it gives ownership to only one person.
2. Webhook: It works great until you want to change the company or project name, or you want to change the profile picture. The only thing you can edit from webhooks is the text.

My solution: Using a bot. With a bot, you can send and edit a message, with the freedom of the bot having dynamic profile pictures and names. If you want to edit a message, you won't lose any reactions. This works great for unique messages like like welcome messages, announcements, or rules.

## How to use

Simply head to https://discord.darketomaly.com, you can invite the bot, log in, and send or edit a message with the bot. You will only see the channels you are moderator in, and that the bot has write permissions on.
